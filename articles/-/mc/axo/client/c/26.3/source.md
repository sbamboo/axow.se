## Standard Community Client
Contains additional QoL features compared to the *Lite* clients.

<details>
    <summary>Mod Changes: (Since 26.2_Community_Client_U3.B2)</summary>

    <span style="color:red;font-weight:bold;">Missing Mods:</span>
        - `polytone`
        - `modelfix`
        - `mixin-trace`

    <span style="color:orange;font-weight:bold;">Skipped:</span>
        - `show-me-your-skin` / `armor-hider` *In Mooare*
        - `enhanced-block-entites` *In Mooare for evaluation*
        - `lazy-language-loading` *In Mooare for evaluation*

    <span style="color:blue;font-weight:bold;">Notes:</span>
        - Kept `animatica-refabricated` instead of `animatica`
        - Kept the `CustomWindowTitle` private fork for 26.x support.
</details>


## Lite Clients
The lite clients are more like optifine-alternatives with the additional content for community stuff like `Simple Voice Chat`.
And contains a lot of the same mods but less then the regular clients.

<details>
    <summary>Mod Changes: (Since 26.2_Community_Client_Lite_U3.B2)</summary>

    <span style="color:red;font-weight:bold;">Still Missing Mods:</span>
        - `modelfix`
        - `mixin-trace`

    <span style="color:orange;font-weight:bold;">Skipped:</span>
        - `polytone` *In standard client for now*
        - `enhanced-block-entites` *In Mooare for evaluation*

    <span style="color:blue;font-weight:bold;">Notes:</span>
        - Kept `animatica-refabricated` instead of `animatica`
        - Kept the `CustomWindowTitle` private fork for 26.x support.
</details>


## Mooare Client
The mooare series are larger modpacks that contain additional mods that I like to play with or that I find usefull for development/server-management.
And contains all of the same mods as the regular clients but with a lot extra added.

<details>
    <summary>Mod Changes: (Since 26.2 Mooare U1 BETA1)</summary>

    <span style="color:red;font-weight:bold;">Missing Mods:</span>
        - `polytone`
        - `more-leaf-particles`
        - `lazy-language-loading`
        - `modelfix`
        - `mixin-trace`
        - `resourcepack-extractor`
        - `voxy`

    <span style="color:orange;font-weight:bold;">Skipped:</span>
        - `big sign writer`

    <span style="color:blue;font-weight:bold;">Notes:</span>
        - No longer using `xaeros zoom out` since it's now part of the main mod as a setting.
        - Kept `animatica-refabricated` instead of `animatica`
        - Kept the `CustomWindowTitle` private fork for 26.x support.
</details>
